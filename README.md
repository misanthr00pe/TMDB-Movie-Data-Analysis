# TMDB-Movie-Data-Analysis
EDA, Regression, Classification, Clustering, Time series analysis

# 🎯 Objective:
To analyze and derive insights from TMDB’s movie dataset by exploring key patterns, trends, and factors affecting movie success (such as popularity, revenue, and ratings). The goal can include:

Identifying what contributes to a successful movie

Exploring revenue trends over the years

Analyzing relationships between budget, genre, runtime, and ratings

Making predictive models (optional advanced goal)
