# 📊 TMDB-Movie-Data-Analysis
This project focuses on exploring trends and patterns within the movie industry using data from The Movie Database (TMDB). The database contains datav in json format. It involves cleaning and analyzing various movie attributes such as budget, revenue, popularity, genre, ratings, and release dates. The goal is to uncover key insights such as factors contributing to a movie’s success, how genre and budget impact revenue, and which years were the most profitable for the industry. Through data visualization and statistical techniques, the project helps draw meaningful conclusions and supports predictive modeling using various machine learning algorithms for future movie performance.
